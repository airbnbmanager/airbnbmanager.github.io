## 🚀 1-Click Fast Setup (Sabse Aasan Tarika)

### Step 1: Node.js Check Karein (Sirf Pehli Baar)
* Agar aapke Windows PC me **Node.js** pehle se install nahi hai, to official website se download karke install kar lijiye:
  👉 [https://nodejs.org](https://nodejs.org) *(LTS Version download karein — Next, Next karke install ho jayega)*.

---

### Step 2: 1-Click Batch File Run Karein
1. Windows Explorer me project folder kholein:
   ```
   airbnbmanager.github.io\whatsapp-bot\
   ```
2. Wahan **`start-windows.bat`** file par **Double Click** karein.
   * Ye file automatically sabhi zaroori packages install kar degi aur server ko `http://localhost:3000` par start kar degi!
   * Black Command Prompt window open rahegi aur green letters me Gateway running dikhayegi.

---

### Step 3: WhatsApp Link / Scan QR Karein
1. Apne browser me ye URL kholein:
   👉 **`http://localhost:3000/qr`**
2. Apne mobile ke WhatsApp me jayein:
   * **Settings ➔ Linked Devices ➔ Link a Device**
   * Screen par dikh rahe QR code ko scan karein.
3. Scan hote hi screen par **"✅ WhatsApp Connected! The Unique Haven Homes Gateway is LIVE 24x7"** likha aa jayega.

### Step 4: CRM Me Test Karein

## ⚡ PC On Hote Hi Automatic Start Kaise Karein? (Windows Startup)

Agar aap chahte hain ki Windows PC restart ya on hote hi ye bot automatically background me shuru ho jaye:

1. Keyboard par press karein: **`Win + R`**
2. Type karein: **`shell:startup`** aur **Enter** dabayein (Startup folder khul jayega).
3. **`start-windows.bat`** file ka **Shortcut** banayein aur is folder me paste kar dein.
4. Ab jab bhi Windows PC on hoga, WhatsApp Bot automatically bina kuch kiye background me start ho jayega!
